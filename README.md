# 341000 VVVF PTS 운행 시뮬레이터

제2종 전기차량 운전면허 학습용 PTS 웹앱입니다. 현재 웹앱은 v1.04.1입니다.

## 사용

- `index.html`을 브라우저에서 열어 실행합니다.
- https://chosunengineering.github.io/vvvf-pts-simulator/?v=4a59a211
- 아이폰 유저는 해당 링크를 이용하여 웹앱으로 사용할 수 있습니다.
- 폰에서 PTS 링크를 Chrome으로 열기
- 오른쪽 위 ⋮ 누르기
- 앱 설치 또는 설치 및 바로가기 만들기 선택
- 설치/추가 누르기

- 
- 아이폰은 Safari에서 링크를 연 뒤 공유 → 홈 화면에 추가 → ‘웹 앱으로 열기’ 켜기 → 추가. (Apple 안내)
- GitHub Pages 배포 중 제공된 웹 주소로 접속할 수 있습니다.
- 설치 가능한 PWA이며, 첫 접속 후 오프라인에서도 일부 기능을 사용할 수 있습니다.

## 안내

10/01 패치내역 > 
제어기기 및 운전집중 탭 디테일관련 피드백과 현 ui기준으로 발생하는 애로사항에 대한 조언을 수용하여 패치하였습니다.
패치내용은 제어핸들 논리오류, 0.5배속 추가, 전체적인 ui개선 등 편의성 개선을 중점으로 진행하였습니다.


요청사항 > 
ai도움을 받으면서 코딩이나 에이전트 및 프롬프트 개념이 없는 상태에서 제작한 프로토 모델을 그대로 올려 ui가 굉장히 불편하실겁니다. 
내부 오브잭트 분리 작업중이며 피트백 및 조언이 절실합니다.
크고 작은 오류와 불편, 유닛 인터페이스 개선 필요사항에 대한 피드백은 해당 텍스트 기반 시뮬레이터 뿐 아닌 타 엔진 시뮬레이터 개발에 큰 도움이 됩니다. 
정말 사소한 사항 이라도 괜찮으니 편히 말씀 주시면 감사 드리겠습니다.

이 앱은 시험 공부용 시뮬레이션입니다. 실제 차량 운용 판단이나 현장 절차에 사용하기엔 부족한 사항이 많습니다.
