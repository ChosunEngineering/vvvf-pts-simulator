# 341000 VVVF PTS 운행 시뮬레이터

제2종 전기차량 운전면허 학습용 PTS 웹앱입니다. 현재 웹앱은 v1.04.1입니다.

## 사용

- `index.html`을 브라우저에서 열어 실행합니다.
- GitHub Pages 배포 후에는 제공된 웹 주소로 접속할 수 있습니다.
- 설치 가능한 PWA이며, 첫 접속 후 오프라인에서도 일부 기능을 사용할 수 있습니다.

## 안내

이 앱은 시험 공부용 시뮬레이션입니다. 실제 차량 운용 판단이나 현장 절차에 사용하지 마세요.
