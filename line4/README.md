# PTS 운전실 · 4호선 전 구간 노선 운행 (`line4/` 폴더)

불암산↔산본 36개 역, 상·하선 각 35구간을 달리는 PTS 운전실 재구성 v9입니다.

- 주소: https://chosunengineering.github.io/vvvf-pts-simulator/line4/
- 노선 데이터: BVE5 수도권전철 4호선 CSV(하선 실측, 상선은 하선을 뒤집은 근사)와 교재 4장(산본↔남태령)
- 주요 기능: ATC/ATS 속도 감시, 주행음(M), 몰입 운전 모드(F), 전조등(L), 5·6장 공부모드와 흐름도

저작권 및 허용 범위는 상위 폴더의 [LICENSE](../LICENSE)를 따릅니다.
